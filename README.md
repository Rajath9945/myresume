# Rajath M — Interactive React Portfolio

A high-end, animated React portfolio based on the resume content.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Included interactions

- Smooth section navigation
- Responsive mobile navigation
- Dark / light theme switch
- Mouse-following ambient glow
- 3D-tilting hero profile card
- Scroll reveal animations
- Interactive skill category filtering
- Animated skill proficiency bars
- Clickable project cards with detailed modal
- Copy-email interaction
- Responsive layout for mobile, tablet and desktop
