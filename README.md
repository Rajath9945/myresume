# Rajath M — Interplanetary Space Explorer & Portfolio

## 🚀 Key Interactive Features

- **2.5D Canvas Orrery Simulator**: Realistic elliptical orbits with 3D isometric inclination tilt, rotating solar corona flares, planetary atmospheres, and twinkling starfield.
- **Flight Controls Deck**:
  - `⏸ Pause` / `▶ Resume` orbital mechanics.
  - Time-warp speed multipliers (`0.5x`, `1x`, `2x`, `4x`).
  - Interactive camera pan, scroll-to-zoom, and `🎯 Center View`.
- **Target Quick-Select**: Fly camera directly to the Sun, Planet Java, Planet AI, Planet DSA, or any celestial body.
- **Holographic Telemetry Drawer**: Clicking any celestial body slides out the HUD with orbital metrics, mastery percentages, and deep-dive technical achievements.
- **Dual Mode Switcher**: Seamlessly toggle between **"🪐 Solar Orrery View"** (3D canvas simulation) and **"📋 Mission Control Dossier View"** (classic structured technical resume for recruiters).

## 🛠️ Run Locally

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev
```

Open the local Vite URL (`http://localhost:5173/`) in your browser.

## 📦 Production Build

```bash
npm run build
npm run preview
```
